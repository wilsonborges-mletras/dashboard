Comandos Prontos para Extrair o CSV no Jira
Como baixar o CSV em 3 cliques:
1. No topo do espaço Design Marketing, clique na aba List (ou use o filtro JQL abaixo).
2. Clique no botão nativo Export > Export CSV (my defaults) no canto superior direito.
3. Arraste o arquivo baixado para qualquer lugar deste painel.
1. JQL: Demandas Ativas do Board (Sem Épicos e Sem Concluídos Antigos) Copiar JQL 
project = "DES" AND issuetype != Epic AND status != "✅ CONCLUÍDO" ORDER BY status ASC, updated DESC
2. JQL: Fechamento Mensal (Ativos + Concluídos nos últimos 30 dias) Copiar JQL 
project = "DES" AND issuetype != Epic AND (status != "✅ CONCLUÍDO" OR updated >= -30d) ORDER BY status ASC
3. Prompt para o Chat do Jira Rovo Copiar Prompt 
"Rovo, monte um filtro JQL do projeto Design Marketing (DES) com todas as demandas em aberto ou concluídas neste mês e me dê o link para abrir na Pesquisa de Itens para eu clicar em Exportar CSV."
